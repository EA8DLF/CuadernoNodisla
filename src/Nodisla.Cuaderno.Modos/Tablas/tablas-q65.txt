# QUE ES ESTO Y POR QUE NO SE PUEDE DEDUCIR
#   Q65 protege el mensaje con un codigo QRA(65,15) sobre GF(64): 15 simbolos de seis bits
#   (13 del mensaje y 2 del CRC) se repiten, se barajan, se pesan con elementos del cuerpo y se
#   acumulan para sacar 50 simbolos de paridad. La baraja y los pesos los eligio quien diseno
#   el codigo; no hay formula que los genere. O se tienen los mismos que todo el mundo o no se
#   decodifica a nadie. Lo mismo vale para las 22 posiciones de sincronismo y para el CRC.
#
# FORMATO
#   SIMBOLOS        : simbolos de informacion, longitud de la palabra y tamano del cuerpo.
#   SINCRONISMO     : las 22 posiciones (contando desde uno, como en el protocolo) de los 85
#                     simbolos emitidos que llevan el tono de sincronismo.
#   ENTRADAS        : que simbolo de informacion (0..14) entra en el acumulador en cada paso.
#                     Son 51 pasos: 50 sacan un simbolo de paridad y el ultimo cierra el
#                     acumulador a cero (propiedad del diseno, que se comprueba al cargar).
#   PESOS           : logaritmo (base alfa, con alfa raiz de x^6+x+1) del peso de cada paso.
#   REPETICIONES    : cuantas veces entra cada simbolo de informacion. Es la misma informacion
#                     vista de otro modo: se cruza con ENTRADAS al cargar y si discrepan se
#                     rechaza el fichero entero.
#   CRC12           : polinomio del CRC de 12 bits, reflejado, tal y como lo usa el protocolo.
