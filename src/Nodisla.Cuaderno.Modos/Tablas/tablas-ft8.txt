# QUE ES ESTO Y POR QUE NO SE PUEDE DEDUCIR
#   El codigo corrector LDPC(174,91) de FT8 son 83 ecuaciones de paridad elegidas a mano por
#   quien diseno el protocolo. No hay formula que las genere: o se tienen las mismas que todo
#   el mundo o no se decodifica a nadie. Son constantes del estandar de facto, como el
#   polinomio de un CRC, y es lo unico de este modem que no esta escrito desde cero.
#
#   AQUI SOLO HAY DATOS. No se ha incorporado ni compilado codigo de ese proyecto: el
#   codificador, el decodificador, el sincronizador y todo lo demas son propios.
#
# QUE NO HACE FALTA QUE ESTE
#   La matriz generadora. Se despeja de estas mismas ecuaciones por eliminacion gaussiana al
#   cargar el codigo, asi que no hay una segunda tabla que pueda discrepar de esta.
#
# FORMATO
#   Primera linea util: bits por palabra y bits de mensaje.
#   Despues, una linea por ecuacion de paridad con los bits que toca, contando desde cero.
#   Los bits de cada linea tienen que sumar cero en modulo dos.
#   La linea MEZCLA-FT4 lleva los diez bytes con los que FT4 revuelve el mensaje.
#

#   83 ecuaciones; 24 de peso 7 y 59 de peso 6; 522 unos en total.
#   Cada uno de los 174 bits aparece en exactamente 3 ecuaciones.
#   Ninguna pareja de ecuaciones comparte mas de un bit: no hay ciclos de longitud cuatro.
#   Codificar y decodificar sin ruido devuelve el mensaje identico.
